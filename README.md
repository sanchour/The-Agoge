# AGOGE 🏛️

> **Spartan Body Transformation Tracker & Protocol Hub**  
> *Discipline is destiny.*

AGOGE is an iOS-first Progressive Web Application (PWA) engineered for structured, multi-phase body transformation protocols (Cuts, Bulks, Maintenance breaks, and Long-Term Milestones).

## ✨ Features

- **Protocol Roadmap & Ripple Engine:** Track target and actual weights, body fat percentages, and lean body mass (LBM) with automatic ripple-forward recalculations across future phases.
- **Daily Discipline & Check-Ins:** Rapid metrics entry, 30-day and 90-day rolling consistency indices, calendar history, and streak logs.
- **The Stoa:** Contingency protocols, 7 core tenets, diagnostic quiz, and Spartan rank journey.
- **Native iOS Polish:** Apple glass UI styling, fluid navigation bar, zero-zoom tactile touch inputs, standalone PWA support, and full offline caching via Service Worker.
- **Privacy First:** All data is stored locally on-device with single-tap JSON backup export and import.

## 🚀 Getting Started

AGOGE requires no build step—it runs directly as modern ES modules.

### Run Locally
Serve the directory with any static HTTP server:
```bash
# Using Python
python -m http.server 8080

# Or using Node.js
node server.js
```
Open `http://localhost:8080` (or `http://localhost:3000`) in your browser or mobile device.
